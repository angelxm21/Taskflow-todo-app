# TaskFlow

A modern and responsive task management application built with HTML, CSS, and JavaScript.

## Overview

* Create, organize, update, and manage tasks
* Clean and productivity-focused user interface
* Automatically saves tasks using browser `localStorage`
* Tasks remain available after refreshing the page
* Responsive design for desktop, tablet, and mobile

## Features

* Create, edit, and delete tasks
* Mark tasks as completed
* Filter tasks by All, Active, and Completed
* Search tasks
* Sort tasks by date, priority, and alphabetical order
* Assign Low, Medium, or High priority
* Add task descriptions and due dates
* Track overall task completion
* View task and priority statistics
* Clear completed or all tasks
* Persistent data using `localStorage`

## Technologies

* HTML5
* CSS3
* JavaScript
* DOM Manipulation
* Event Handling
* Event Delegation
* LocalStorage
